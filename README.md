# Fitness Helper

In my project, I developed a Java application called Fitness Helper during Spring Semester 2024 as part of my Programming course. The application calculates estimated daily calorie intake, protein intake, and water requirements based on the user's information, including height, weight, age, and gender.

## Implementations

In this project, I implemented the application using three different programming approaches, which are procedural programming, object-oriented programming, and event-driven programming.

On one hand, the procedural implementation uses methods to perform the different calculations and process the user's information. Another approach I implemented is object-oriented programming, where I used separate classes to manage user information and perform the fitness-related calculations.

On the other hand, I also implemented an event-driven version using Java Swing, where the user can enter their information through a graphical user interface and perform the calculations using the application.

## Technologies Used

I used Java to develop the application and Java Swing to implement the graphical user interface.
